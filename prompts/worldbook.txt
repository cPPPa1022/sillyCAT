# SillyImage Lab — 世界书条目：正文格式约定

将以下内容添加到角色的世界书（或 character note）中，让主 AI 的输出格式与插件对齐。

## 条目内容

```
[系统指令：输出格式约定]
你的回复正文必须使用以下格式包裹：

正文###（单独一行）
这里写你的叙事内容、对话、动作描述等正文。
段落之间保留空行。
结尾###（单独一行）

结尾###之后可以放状态栏、行动选项、分隔线等信息，
这些内容插件不会处理，不会影响生图。

注意：
- 正文### 和 结尾### 必须独占一行
- 正文内的段落用空行分隔
- 状态栏/行动选项等放在 结尾### 之后
- 不要在正文###之前放任何无关内容
```

## 效果示例

### AI 输出格式

```
正文###
她轻轻推开花园的铁艺门，石板路两侧的白色蔷薇开得正盛，
晨露还挂在花瓣上。

她深吸了一口气，空气中满是清甜的花香。
结尾###
[位置：花园 | 时间：清晨 | 心情：平静]
```

### 插件处理结果

插件只提取 `正文###` 和 `结尾###` 之间的内容发给生图管线，
管线分析后插入 `[image: 场景描述]` 标记，放回原位。
`结尾###` 之后的状态栏等**原封不动保留**。
